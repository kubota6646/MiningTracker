修正された重大なバグ
============================================================

【問題】HikariCP MySQL接続エラー

エラーメッセージ:
```
com.zaxxer.hikari.pool.HikariPool$PoolInitializationException: 
Failed to initialize pool: Unsupported character encoding 'utf8mb4'
```

影響: MySQLモードでプラグインが起動できない

【原因】
文字エンコーディング設定をDataSourceプロパティとして設定していた。
MySQL JDBC Driverでは、これらの接続パラメータはJDBC URL内で
指定する必要がある。

【解決方法】
接続パラメータをJDBC URLパラメータとして正しく設定。

修正前:
```java
hikariConfig.addDataSourceProperty("characterEncoding", "utf8mb4");
```

修正後:
```java
String jdbcUrl = "jdbc:mysql://host:port/db?characterEncoding=utf8mb4";
hikariConfig.setJdbcUrl(jdbcUrl);
```

技術的詳細
============================================================

【HikariCP設定の分類】

1. JDBC URLパラメータ（接続レベル）
   - 形式: jdbc:mysql://host:port/db?param=value
   - 用途: 接続、認証、文字セット、SSL等
   - 例:
     * useSSL=false
     * serverTimezone=UTC
     * characterEncoding=utf8mb4
     * allowPublicKeyRetrieval=true

2. DataSourceプロパティ（最適化）
   - 形式: hikariConfig.addDataSourceProperty("key", "value")
   - 用途: パフォーマンス最適化、キャッシュ設定
   - 例:
     * cachePrepStmts=true
     * prepStmtCacheSize=250
     * rewriteBatchedStatements=true

【修正の重要性】
この修正により、HikariCPとMySQL JDBC Driverが正しく連携し、
接続プールの初期化が成功するようになった。
